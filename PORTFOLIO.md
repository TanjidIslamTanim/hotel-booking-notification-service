# Hotel Booking Notification Service project portfolio

This repository now includes a responsive, static case study at `portfolio/index.html`.

## Publish with GitHub Pages

1. Open **Settings → Pages** and select **GitHub Actions** as the build source.
2. Open **Actions → Deploy project portfolio → Run workflow** and select `main`.
3. Wait for the deployment to succeed. The expected address is https://tanjidislamtanim.github.io/hotel-booking-notification-service/.

Only the `portfolio/` directory is published. The actual application or backend is not deployed.

There were no UI screenshots in the source repository; illustrations are clearly labelled as illustrative.

Static backend case study, not a hosted service. Source code does not demonstrate production email delivery or a publicly running Kafka cluster.
